## 🧩 About

**Modern Warfare 3 Companion** is a curated list of Modern Warfare 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, startpoint switcher
- **Quality-of-Life Helpers** — loadout catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Startpoint Switcher — practice from any checkpoint
- Show Hitboxes — visualize obstacle hitboxes
- Replay Notes — record and review mission runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Loadout Catalog — browse weapons, attachments, camos, emblems
- Custom Skin Notes — organize player cosmetics
- Solid overlay Trail — improved overlay visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-mission
- Jump Buffer Notes — chain complex maneuvers in the editor
